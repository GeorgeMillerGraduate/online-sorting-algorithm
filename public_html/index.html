Watching and Hearing Algorithms Work

Sorting algorithms arrange a collection of values into a defined order. Although every algorithm displayed here ultimately produces the same ascending sequence, the route taken to reach that result can be very different.

The visualisation maps array values to both bar height and sound. Lower values produce lower-frequency tones while larger values produce higher-frequency tones, allowing the progress of the algorithm to be heard as well as seen.

Simple algorithms such as Bubble Sort, Selection Sort and Insertion Sort make their decisions directly within the array. More advanced approaches such as Merge Sort and Quick Sort divide the problem into smaller sections.
