About the algorithms

Bubble compares neighbours. Selection finds the next minimum. Insertion builds a sorted prefix. Merge combines sorted sections. Quick partitions around a pivot.

Reset restores the original array. Switching algorithms uses that same starting data. Shuffle rearranges those values; Generate creates new values.

Lower values produce lower notes. The changes counter includes swaps and value-changing writes.
